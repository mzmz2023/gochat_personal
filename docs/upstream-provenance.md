## 一、来源与基线

- 提交号：`1ff674844d367ae0bff87fffe56f9b03181bd294`
- 提交时间：2026-09-01 14:06:25 +0800
- 提交标题：`Merge pull request #74 from funnyjacy/fix/concurrency-crashes`
- 提交树对象：`799815b89feb5d9500e6a44a3967aab0b78b1887`

上游提交可通过 <https://github.com/LockGit/gochat/commit/1ff674844d367ae0bff87fffe56f9b03181bd294> 在线核对。基线锁定后，上游后续提交不会自动进入本仓库；如需升级基线，应单独提交并同步更新本文档。

本快照以文件形式保存，不包含上游的 `.git` 提交历史，也不合并、改写上游分支记录，来源以固定提交号追溯。
